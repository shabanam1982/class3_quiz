Unit 3: Class Calendar Chronicle 📅 22 Q

What is a chronicle?
A chronicle is a record of events that took place in the past. It is arranged in the order in which the events happened — this is called chronological order.

Quick Tips — A table is useful for:
• Arranging information in rows and columns
• Finding information easily
• Comparing different information
• Catching the attention of the reader

Two types of lists:
• Bulleted list — uses dots, squares, arrows, ticks (order does NOT matter)
• Numbered list — uses 1, 2, 3 / a, b, c / i, ii, iii (order DOES matter)
