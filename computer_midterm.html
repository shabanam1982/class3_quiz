📅 Unit 3 — Class Calendar Chronicle

A. Multiple Choice Questions ✏️

1. What is a chronicle?

It is a special kind of record arranged by date.
✅ A chronicle is a record of events that took place in the past, arranged in the order they happened. This order is called chronological order.

2. The order in which events happened one after another is called:

The word is close to the word 'chronicle'.
✅ Chronological order means arranging events by the date and time they happened. A chronicle uses chronological order.

3. What information does a student directory contain?

Think of a phone book, but for students.
✅ A student directory keeps information such as names, phone numbers, and addresses so classmates can contact each other easily.

4. A table is made up of:

One goes side-to-side and the other goes up-and-down.
✅ A table is made up of rows (going across) and columns (going down). The small boxes are called cells.

5. Which of these is NOT a use of a table?

Tables help us with information, not sound.
✅ Tables are used to arrange, compare, and find information. Playing music is not what a table is used for.

6. If there are 35 students in a class and you record 3 points of information for each, how many rows and columns are needed?

Each student gets one row. Each piece of info gets one column.
✅ One row for each student (35 rows). One column for each point of information (3 columns). So we need 35 rows and 3 columns.

✅ VIBGYOR stands for Violet, Indigo, Blue, Green, Yellow, Orange, Red — the seven colours of the rainbow.

Numbers show which comes first, second, third.

✅ A dictionary (alphabetical order), a to-do list (order of tasks), and a book's contents (chapter order) all have a fixed order, so they are numbered lists.

1. What is a food chain? Give one example of a food chain. (about 70 words)

Think about who eats what in the jungle.
Sample Answer: A food chain is a chain of living things (organisms) where one feeds on another in a specific order. It shows who eats whom in nature. Example of a food chain on land: Grass → Zebra → Lion (The zebra eats grass, and the lion eats the zebra.)

2. Explain the underwater food chain using the marine food pyramid. (about 70 words)

Start with plants and end with the biggest sea animal.
Sample Answer: The underwater food chain works like this: 1. Small fishes eat seaweeds (water plants). 2. Big fishes eat the small fishes. 3. Whales and sharks eat the big fishes. So the food chain is: Seaweeds → Small fishes → Big fishes → Whales/Sharks.

A. Multiple Choice Questions ✏️

1. What is an avatar?

If you make a mistake, Undo helps you fix it.
✅ The Undo button takes back the last action, like when we make a mistake and want to go back one step.

The colour of water or the sky.
✅ Motion blocks are blue in colour. These blocks move the character around on the stage.

Right means the right side.
✅ The Move Right block moves the character 1 grid square to the right side.

5. What does the Hop block do?

Hop means to jump up and come back down.
✅ The Hop block makes the character jump up by 2 grid squares and then come down again, like hopping.

6. What does the Go Home block do?

Home is the place where the character started.
✅ The Go Home block takes the character back to where it started. 'Home' here means the starting position.

7. What colour are the Triggering blocks (like Start on Green Flag) in ScratchJr?

The colour of the sun or a banana.
✅ Triggering blocks are yellow. They start the script when something happens, like the Green Flag being clicked.

8. What does the Start on Green Flag block do?

It makes the script begin when we click the flag.
✅ This yellow block starts the script when we click on the green flag. It is like saying 'Begin now!'

9. What colour are the End blocks in ScratchJr?

Red usually means stop.
✅ End blocks are red in colour. They are used to mark the end of a script.

10. What does the Repeat Forever block do?

Forever means it never ends.
✅ Repeat Forever makes the script run again and again, never stopping, until we press stop.

11. What colour are the Sound blocks in ScratchJr?

The colour of grass or leaves.
✅ Sound blocks are green. They add audio (sound) clips to our characters, like a pop sound.

12. What does the Go to Page block do?

It moves us between the pages of our project.
✅ The Go to Page block moves us from one page to another page in our ScratchJr project.

13. What colour are the Control blocks (Wait, Stop, Set Speed, Repeat) in ScratchJr?

The colour of gold.
✅ Control blocks are golden (orange-yellow). They control the script — like pausing, repeating, or stopping it.

14. Which Control block will be used to make the plane move very fast?

The name of the block tells you what it does.
✅ The Set Speed block changes how fast the character moves. To make the plane move very fast, we use Set Speed and choose fast.

15. Which block do characters use to communicate (talk) with each other?

The name of the block has the word 'Message' in it.
✅ The Send Message block lets one character send a message to another character. The other character receives it with the Start on Message block.

16. Which block is used at the BEGINNING of a script?

The script needs a block that says 'begin here'.
✅ Scripts start with a yellow Triggering block like Start on Green Flag, Start on Tap, Start on Bump, or Start on Message.
