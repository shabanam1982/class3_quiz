Class 3 Practice Website

An interactive practice website that helps Class 3 students prepare for their exams with engaging, subject-wise worksheets, quizzes, and practice activities.

🌟 Features
🧒 Child-friendly and easy-to-use interface
📱 Works on computers, tablets, and mobile devices
📝 Interactive practice questions
🎯 Subject-wise practice
⚡ Instant feedback for interactive activities
🏠 Simple navigation from the main page
🎨 Designed for independent practice at home
📖 Subjects

The website currently includes practice materials for:

Subject	Topics / Content
📐 Math	Class 3 mathematics practice
🔬 Science	Class 3 science practice
🌍 Social Science	Class 3 social studies practice
🌸 Kannada	Alphabets, Kagunita, Ottakshara, Chitte poem
💻 Computer	Computer-related practice activities
☪️ Islamic Studies	Islamic studies practice
🇬🇧 English	English practice activities
🧩 Mixed Word Problems	Mixed mathematical word problems
🚀 How to Use

Open the website:

https://shabanam1982.github.io/class3_quiz/

From the homepage, select the subject you want to practice.

For example:

Home
 │
 ├── 📐 Math
 ├── 🔬 Science
 ├── 🌍 Social Science
 ├── 🌸 Kannada
 ├── 💻 Computer
 ├── ☪️ Islamic Studies
 ├── 🇬🇧 English
 └── 🧩 Mixed Word Problems

Click on any subject to begin practicing.
